# MT4Sugar — 2. Prices

> Current prices and spread in one line, plus a blocking wait-for-price helper. All read live quotes under the hood.

```cpp
MT4Sugar sugar("mt4.mrpc.pro", 443);
sugar.connect(1235959737, "password", "EGlobal-Demo");
```

---

## `getBid` / `getAsk` / `getSpread`

```cpp
double getBid(const std::string& symbol);      // current bid
double getAsk(const std::string& symbol);      // current ask
double getSpread(const std::string& symbol);   // ask - bid (price units)
```

```cpp
std::printf("EURUSD %.5f / %.5f  spread %.5f\n",
            sugar.getBid("EURUSD"), sugar.getAsk("EURUSD"), sugar.getSpread("EURUSD"));
```

> For several figures at once, prefer `getPriceInfo()` (one call) over three separate getters.

---

## `getPriceInfo(symbol)`

```cpp
PriceInfo getPriceInfo(const std::string& symbol);
```

Bid, ask, spread and quote time in one call.

**Returns — `PriceInfo`:** `symbol`, `bid`, `ask`, `spread` (ask − bid), `time` (UTC seconds).

```cpp
PriceInfo p = sugar.getPriceInfo("EURUSD");
std::printf("%s %.5f/%.5f  spread %.5f\n", p.symbol.c_str(), p.bid, p.ask, p.spread);
```

---

## `waitForPrice(symbol, targetBid, timeoutMs=10000)`

```cpp
PriceInfo waitForPrice(const std::string& symbol, double targetBid, int timeoutMs = 10000);
```

Poll until the bid reaches `targetBid` (or just **any** tick when `targetBid == 0`), up to `timeoutMs`. Returns the last price seen; on timeout the returned `PriceInfo` has an **empty `symbol`**.

```cpp
PriceInfo hit = sugar.waitForPrice("EURUSD", 1.10000, /*timeoutMs*/ 5000);
if (hit.symbol.empty()) std::puts("timed out");
else std::printf("reached %.5f\n", hit.bid);

// any next tick:
PriceInfo next = sugar.waitForPrice("EURUSD", 0.0, 2000);
```

> **Blocking.** `waitForPrice` polls on the calling thread. For push-style updates use [`MT4Service::subscribeTicks`](../MT4Service/5.%20Streaming_Methods.md).

## 🔧 Patterns & worked examples

### Skip entries when the spread is too wide

```cpp
bool spreadOK(MT4Sugar& sugar, const std::string& sym, double maxPips) {
    PriceInfo p = sugar.getPriceInfo(sym);
    double point = sugar.getSymbolInfo(sym).point;
    double pip   = (sugar.getSymbolDigits(sym) % 2 == 1) ? point * 10 : point;
    return (p.spread / pip) <= maxPips;             // e.g. don't trade if spread > 3 pips
}
```

### Watchlist snapshot table

```cpp
void snapshot(MT4Sugar& sugar, const std::vector<std::string>& syms) {
    std::printf("%-8s %12s %12s %10s\n", "SYMBOL", "BID", "ASK", "SPREAD");
    for (const auto& s : syms) {
        PriceInfo p = sugar.getPriceInfo(s);
        std::printf("%-8s %12.5f %12.5f %10.5f\n", s.c_str(), p.bid, p.ask, p.spread);
    }
}
```

### Wait for a breakout, then act

```cpp
// block until EURUSD prints 1.1000+, up to 30s, then enter
PriceInfo hit = sugar.waitForPrice("EURUSD", 1.10000, /*timeoutMs*/ 30000);
if (!hit.symbol.empty()) {
    int t = sugar.buyMarket("EURUSD", 0.10);
    std::printf(t ? "entered #%d\n" : "entry rejected\n", t);
} else {
    std::puts("no breakout within 30s");
}
```

### Mid price & simple momentum tick

```cpp
double mid(MT4Sugar& sugar, const std::string& sym) {
    PriceInfo p = sugar.getPriceInfo(sym);
    return (p.bid + p.ask) / 2.0;
}
// sample twice to see direction
double a = mid(sugar, "EURUSD");
PriceInfo next = sugar.waitForPrice("EURUSD", 0.0, 2000);   // any next tick
double b = next.symbol.empty() ? a : (next.bid + next.ask) / 2.0;
std::printf("%s\n", b > a ? "up" : b < a ? "down" : "flat");
```
