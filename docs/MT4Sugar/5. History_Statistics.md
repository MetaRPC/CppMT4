# MT4Sugar — 5. History & Statistics

> Closed-order history over ready-made windows, period profits, and a one-call daily summary. Day boundaries are **UTC**.

```cpp
MT4Sugar sugar("mt4.mrpc.pro", 443);
sugar.connect(1235959737, "password", "EGlobal-Demo");
```

---

## History windows

```cpp
std::vector<HistoryOrder> getHistoryToday();
std::vector<HistoryOrder> getHistoryYesterday();
std::vector<HistoryOrder> getHistoryThisWeek();
std::vector<HistoryOrder> getHistoryThisMonth();
std::vector<HistoryOrder> getHistoryDateRange(int64_t fromUnix, int64_t toUnix);
```

Each returns closed orders in that window as `HistoryOrder` (ticket, symbol, type, lots, open/close price, profit, swap, commission, open/close time) — same struct as [MT4Service · History](../MT4Service/2.%20Orders_History.md).

```cpp
auto today = sugar.getHistoryToday();
std::printf("%zu trades closed today\n", today.size());

#include <ctime>
int64_t now = (int64_t)std::time(nullptr);
auto custom = sugar.getHistoryDateRange(now - 30*24*3600, now);   // last 30 days
```

## Period profit

```cpp
double getProfitToday();
double getProfitThisWeek();
double getProfitThisMonth();
```

Net realized profit (incl. swap & commission) over the window.

```cpp
std::printf("today %.2f  week %.2f  month %.2f\n",
            sugar.getProfitToday(), sugar.getProfitThisWeek(), sugar.getProfitThisMonth());
```

## `getDailyStats()`

```cpp
DailyStats getDailyStats();
```

Today's win/loss summary in one call.

**Returns — `DailyStats`:**

| Field | Type | Description |
|-------|------|-------------|
| `totalOrders` | `int` | Orders closed today |
| `winningOrders` / `losingOrders` | `int` | Win / loss counts |
| `winRate` | `double` | Winning / total, **percent** |
| `totalProfit` | `double` | Net profit (incl. swap & commission) |
| `bestOrder` / `worstOrder` | `double` | Largest win / loss |

```cpp
DailyStats d = sugar.getDailyStats();
std::printf("Today: %d trades, win rate %.1f%%, net %.2f (best %.2f / worst %.2f)\n",
            d.totalOrders, d.winRate, d.totalProfit, d.bestOrder, d.worstOrder);
```

> **Non-trades excluded.** Balance/credit history entries are not counted as trades in these aggregates.

## 🔧 Patterns & worked examples

### End-of-day report line

```cpp
void dailyReport(MT4Sugar& sugar) {
    DailyStats d = sugar.getDailyStats();
    std::printf("Today: %d trades | win %.1f%% | net %+.2f | best %+.2f | worst %+.2f\n",
                d.totalOrders, d.winRate, d.totalProfit, d.bestOrder, d.worstOrder);
}
```

### Period P/L at a glance

```cpp
void pnlOverview(MT4Sugar& sugar) {
    std::printf("Day %+.2f | Week %+.2f | Month %+.2f\n",
                sugar.getProfitToday(), sugar.getProfitThisWeek(), sugar.getProfitThisMonth());
}
```

### Best / worst closed trade this week

```cpp
void extremes(MT4Sugar& sugar) {
    double best = -1e18, worst = 1e18;
    for (const auto& h : sugar.getHistoryThisWeek()) {
        double net = h.profit + h.swap + h.commission;
        best = std::max(best, net); worst = std::min(worst, net);
    }
    std::printf("best %+.2f  worst %+.2f\n", best, worst);
}
```

### Realized P/L by symbol (custom range)

```cpp
#include <map>
#include <ctime>
std::map<std::string,double> pnlBySymbol(MT4Sugar& sugar, int days) {
    int64_t now = (int64_t)std::time(nullptr);
    std::map<std::string,double> m;
    for (const auto& h : sugar.getHistoryDateRange(now - days*24*3600, now))
        m[h.symbol] += h.profit + h.swap + h.commission;
    return m;
}
```
