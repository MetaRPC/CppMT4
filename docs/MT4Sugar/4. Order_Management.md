# MT4Sugar — 4. Order Management & Info

> Close, modify and inspect live orders. Remember MT4 has **no "positions"** — these cover market **and** pending orders.

```cpp
MT4Sugar sugar("mt4.mrpc.pro", 443);
sugar.connect(1235959737, "password", "EGlobal-Demo");
```

---

## Closing

```cpp
bool closeOrder(int ticket);                        // close a market order / delete a pending
bool closeOrderPartial(int ticket, double lots);    // close part of a market order
int  closeAllOrders();                              // close/delete every order; returns count
int  closeAllBySymbol(const std::string& symbol);   // same, for one symbol; returns count
```

`closeOrder` / `closeOrderPartial` return `false` on an ordinary rejection (they don't throw). The `closeAll*` variants return how many were closed.

```cpp
sugar.closeOrder(ticket);                 // full close / delete
sugar.closeOrderPartial(ticket, 0.05);    // scale out 0.05 lots
int n = sugar.closeAllOrders();
std::printf("closed %d orders\n", n);
```

---

## Modifying

```cpp
bool modifyOrderSL(int ticket, double sl);                  // set SL only (keeps TP)
bool modifyOrderTP(int ticket, double tp);                  // set TP only (keeps SL)
bool modifyOrderSLTP(int ticket, double sl, double tp);     // set both
```

`sl` / `tp` are **prices**. All three return `false` instead of throwing on an ordinary rejection (e.g. stops too close → MQL4 `130`).

```cpp
sugar.modifyOrderSLTP(ticket, /*sl*/ 1.09000, /*tp*/ 1.11000);
sugar.modifyOrderSL(ticket, 1.09500);     // move the stop up (keep TP)
```

## Inspecting

```cpp
std::vector<Order> getOpenOrders();                            // all live orders
std::vector<Order> getOrdersBySymbol(const std::string& symbol);
Order getOrderByTicket(int ticket, bool& found);               // found=false if none
bool  hasOpenOrder(const std::string& symbol);                 // any order on the symbol?
int   countOpenOrders();                                       // number of live orders
double getTotalProfit();                                       // summed floating profit
double getProfitBySymbol(const std::string& symbol);           // floating profit on one symbol
```

The `Order` struct (ticket, symbol, type, lots, prices, SL/TP, profit, …) is the same as [MT4Service · Orders](../MT4Service/2.%20Orders_History.md); use `o.isPending()` / `o.isBuy()`.

```cpp
std::printf("%d open, floating %.2f\n", sugar.countOpenOrders(), sugar.getTotalProfit());

bool found;
Order o = sugar.getOrderByTicket(ticket, found);
if (found) std::printf("#%d %s %.2f lots, P/L %.2f\n", o.ticket, o.symbol.c_str(), o.lots, o.profit);

if (sugar.hasOpenOrder("EURUSD"))
    std::printf("EURUSD exposure P/L %.2f\n", sugar.getProfitBySymbol("EURUSD"));
```

## 🔧 Patterns & worked examples

### Close every losing market order

```cpp
int cutLosers(MT4Sugar& sugar) {
    int n = 0;
    for (const auto& o : sugar.getOpenOrders())
        if (!o.isPending() && o.profit < 0 && sugar.closeOrder(o.ticket)) ++n;
    return n;
}
```

### Take partial profit at a target

```cpp
void scaleOut(MT4Sugar& sugar, const std::string& sym, double takeProfitCash) {
    if (sugar.getProfitBySymbol(sym) < takeProfitCash) return;
    for (const auto& o : sugar.getOrdersBySymbol(sym))
        if (!o.isPending() && o.profit > 0)
            sugar.closeOrderPartial(o.ticket, o.lots / 2.0);   // bank half
}
```

### Move every open order to break-even once in profit

```cpp
void breakEvenAll(MT4Sugar& sugar, double triggerProfit) {
    for (const auto& o : sugar.getOpenOrders()) {
        if (o.isPending() || o.profit < triggerProfit) continue;
        sugar.modifyOrderSL(o.ticket, o.openPrice);            // SL → entry, keep TP
    }
}
```

### Flatten a symbol on a cash stop

```cpp
void capLoss(MT4Sugar& sugar, const std::string& sym, double maxLoss) {
    if (sugar.getProfitBySymbol(sym) <= -maxLoss)
        std::printf("closed %d on %s\n", sugar.closeAllBySymbol(sym), sym.c_str());
}
```

### Status line of live exposure

```cpp
void status(MT4Sugar& sugar) {
    std::printf("open %d | floating %.2f\n", sugar.countOpenOrders(), sugar.getTotalProfit());
}
```
