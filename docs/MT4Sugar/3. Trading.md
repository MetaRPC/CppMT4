# MT4Sugar — 3. Trading

> Open market and pending orders in one line. Every helper **returns the ticket** (`int`) — or **`0`** on an ordinary rejection (it never throws for a broker refusal; the MQL4 error is swallowed into the `0`).

```cpp
MT4Sugar sugar("mt4.mrpc.pro", 443);
sugar.connect(1235959737, "password", "EGlobal-Demo");
```

> **🛑 `0` = rejected.** Always check the return. *(Underlying throw model: [MT4Account · OrderSend](../MT4Account/4.%20Trading_Operations/OrderSend.md).)*

---

## Simple market & pending

```cpp
int buyMarket (const std::string& symbol, double volume);
int sellMarket(const std::string& symbol, double volume);
int buyLimit  (const std::string& symbol, double volume, double price);
int sellLimit (const std::string& symbol, double volume, double price);
int buyStop   (const std::string& symbol, double volume, double price);
int sellStop  (const std::string& symbol, double volume, double price);
```

* **Market:** `buyMarket` / `sellMarket` fill at the current price.
* **Limit:** sits *better* than market (buy below, sell above).
* **Stop:** sits *worse* than market (buy above, sell below).

```cpp
int t = sugar.buyMarket("EURUSD", 0.10);
if (!t) std::puts("rejected");

sugar.sellLimit("EURUSD", 0.10, 1.10500);   // pending sell-limit above market
```

## With stop-loss / take-profit (absolute prices)

```cpp
int buyMarketWithSLTP (const std::string& symbol, double volume, double sl, double tp);
int sellMarketWithSLTP(const std::string& symbol, double volume, double sl, double tp);
int buyLimitWithSLTP  (const std::string& symbol, double volume, double price, double sl, double tp);
int sellLimitWithSLTP (const std::string& symbol, double volume, double price, double sl, double tp);
```

`sl` / `tp` are **prices** (use [`calculateSLTP`](./6.%20Symbols_Risk.md) to derive them from pip distances).

```cpp
int t = sugar.buyMarketWithSLTP("EURUSD", 0.10, /*sl*/ 1.09500, /*tp*/ 1.10500);

// pending buy-limit with stops
sugar.buyLimitWithSLTP("EURUSD", 0.10, /*price*/ 1.09000, /*sl*/ 1.08500, /*tp*/ 1.10000);
```

## With stop-loss / take-profit (pip distances)

```cpp
int buyMarketWithPips (const std::string& symbol, double volume, double slPips, double tpPips);
int sellMarketWithPips(const std::string& symbol, double volume, double slPips, double tpPips);
```

SL/TP given as **pip distances from entry** — the helper computes the prices for you (pip = `point × 10` on 3/5-digit symbols).

```cpp
int t = sugar.buyMarketWithPips("EURUSD", 0.10, /*SL*/ 20, /*TP*/ 40);
```

## 🔧 Patterns & worked examples

### Size by risk, then enter with a bracket

```cpp
double lots = sugar.calculatePositionSize("EURUSD", /*risk%*/ 1.0, /*SL pips*/ 20);
int ticket  = sugar.buyMarketWithPips("EURUSD", lots, 20, 40);   // 1:2 reward:risk
if (ticket) std::printf("opened #%d, %.2f lots\n", ticket, lots);
```

### Safe entry — validate, then trade

```cpp
bool safeBuy(MT4Sugar& sugar, const std::string& sym, double lots, double slPips, double tpPips) {
    std::string why;
    if (!sugar.canOpenOrder(sym, lots, why)) { std::printf("skip: %s\n", why.c_str()); return false; }
    int t = sugar.buyMarketWithPips(sym, lots, slPips, tpPips);
    if (!t) { std::puts("broker rejected"); return false; }
    std::printf("opened #%d\n", t);
    return true;
}
```

### Pending-order ladder (accumulate on dips)

```cpp
void buyLadder(MT4Sugar& sugar, const std::string& sym, double lots, int rungs, double gapPips) {
    double point = sugar.getSymbolInfo(sym).point;
    double pip   = (sugar.getSymbolDigits(sym) % 2 == 1) ? point * 10 : point;
    double bid   = sugar.getBid(sym);
    for (int i = 1; i <= rungs; ++i) {
        int t = sugar.buyLimit(sym, lots, bid - i * gapPips * pip);
        std::printf(t ? "  rung %d #%d\n" : "  rung %d rejected\n", i, t);
    }
}
```

### Retry a requoted market order

```cpp
int buyRetry(MT4Sugar& sugar, const std::string& sym, double lots, int tries = 3) {
    for (int i = 0; i < tries; ++i) {
        int t = sugar.buyMarket(sym, lots);          // 0 on rejection (requote/price changed)
        if (t) return t;
        std::this_thread::sleep_for(std::chrono::milliseconds(200));   // let price settle
    }
    return 0;
}
```

### Market order with explicit SL/TP prices

```cpp
double entry = sugar.getAsk("EURUSD");
double sl, tp;
sugar.calculateSLTP("EURUSD", "buy", entry, /*SLpips*/ 25, /*TPpips*/ 50, sl, tp);
int t = sugar.buyMarketWithSLTP("EURUSD", 0.10, sl, tp);
```
