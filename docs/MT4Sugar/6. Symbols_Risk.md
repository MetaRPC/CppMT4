# MT4Sugar — 6. Symbols & Risk

> Quick symbol facts, plus risk-based position sizing and pre-trade checks. These are the numbers you combine to size and validate an order — MT4 has **no server-side `orderCheck` / `orderCalc*`**, so the sizing helpers compute client-side.

```cpp
MT4Sugar sugar("mt4.mrpc.pro", 443);
sugar.connect(1235959737, "password", "EGlobal-Demo");
```

---

## Symbol information

```cpp
SymbolInfo getSymbolInfo(const std::string& symbol);    // full params (digits, point, contract, margins, …)
std::vector<std::string> getAllSymbols();               // every symbol name
bool isSymbolAvailable(const std::string& symbol);      // the broker knows this symbol
int  getMinStopLevel(const std::string& symbol);        // min SL/TP distance, in points
int  getSymbolDigits(const std::string& symbol);        // price decimal places
```

`getSymbolInfo` returns the `SymbolInfo` struct — same as [MT4Service · Symbols](../MT4Service/3.%20Symbols_Quotes.md).

```cpp
if (sugar.isSymbolAvailable("XAUUSD")) {
    int digits = sugar.getSymbolDigits("XAUUSD");
    int minStop = sugar.getMinStopLevel("XAUUSD");
    std::printf("XAUUSD digits=%d  min stop=%d pts\n", digits, minStop);
}
```

## Risk & sizing

```cpp
// Lot size so a stopLossPips stop risks riskPercent% of the balance.
double calculatePositionSize(const std::string& symbol, double riskPercent, double stopLossPips);

// Largest lot the current free margin can open on this symbol.
double getMaxLotSize(const std::string& symbol);

// Can a volume-lot order be opened now? reason explains a false.
bool canOpenOrder(const std::string& symbol, double volume, std::string& reason);

// Margin to open volume lots. MT4 has no margin RPC — estimated from the symbol's
// margin-initial (or contract size / leverage).
double calculateRequiredMargin(const std::string& symbol, double volume);

// Absolute SL/TP prices for a direction ("buy"/"sell") given pip distances from entry.
void calculateSLTP(const std::string& symbol, const std::string& direction, double entryPrice,
                   double stopLossPips, double takeProfitPips, double& slOut, double& tpOut);
```

```cpp
// risk 1% of balance on a 20-pip stop
double lots = sugar.calculatePositionSize("EURUSD", 1.0, 20);
lots = std::min(lots, sugar.getMaxLotSize("EURUSD"));   // cap by free margin

std::string why;
if (!sugar.canOpenOrder("EURUSD", lots, why)) {
    std::printf("cannot open: %s\n", why.c_str());
} else {
    double sl, tp;
    sugar.calculateSLTP("EURUSD", "buy", sugar.getAsk("EURUSD"), 20, 40, sl, tp);
    sugar.buyMarketWithSLTP("EURUSD", lots, sl, tp);
}
```

> **`calculateRequiredMargin`** is an estimate (no server margin RPC on MT4): it uses the symbol's `marginInitial × volume`, else `contractSize × volume × price / leverage`.

## 🔧 Patterns & worked examples

### Full risk-managed entry

```cpp
bool safeEntry(MT4Sugar& sugar, const std::string& sym, double riskPct, double slPips, double tpPips) {
    double lots = sugar.calculatePositionSize(sym, riskPct, slPips);
    lots = std::min(lots, sugar.getMaxLotSize(sym));            // never exceed free margin

    std::string why;
    if (!sugar.canOpenOrder(sym, lots, why)) { std::printf("skip: %s\n", why.c_str()); return false; }

    int ticket = sugar.buyMarketWithPips(sym, lots, slPips, tpPips);
    return ticket != 0;
}
```

### Ensure a symbol is tradable before using it

```cpp
bool ready(MT4Sugar& sugar, const std::string& sym) {
    if (!sugar.isSymbolAvailable(sym)) { std::printf("%s unknown\n", sym.c_str()); return false; }
    SymbolInfo s = sugar.getSymbolInfo(sym);
    return s.tradeMode == 4;                                    // SYMBOL_TRADE_MODE_FULL
}
```

### Clamp a requested lot to the symbol's grid

```cpp
double clampLot(MT4Sugar& sugar, const std::string& sym, double lots) {
    SymbolInfo s = sugar.getSymbolInfo(sym);
    lots = std::max(s.volumeMin, std::min(lots, s.volumeMax));
    if (s.volumeStep > 0) lots = std::round(lots / s.volumeStep) * s.volumeStep;
    return lots;                                                // avoids MQL4 131 (invalid volume)
}
```

### Scan all USD pairs the broker offers

```cpp
#include <vector>
std::vector<std::string> usdPairs(MT4Sugar& sugar) {
    std::vector<std::string> out;
    for (const auto& name : sugar.getAllSymbols())
        if (name.find("USD") != std::string::npos) out.push_back(name);
    return out;
}
```

### Estimate margin before committing

```cpp
if (sugar.calculateRequiredMargin("EURUSD", 1.0) < sugar.getFreeMargin())
    std::puts("1.0 lot is affordable");
```
