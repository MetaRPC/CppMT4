# MT4Sugar — 1. Connection & Account

> Connect, check liveness, and read account money figures — each a self-contained one-liner. The balance/margin getters each fetch one fresh account summary.

```cpp
#include <metarpc/mt4_sugar.hpp>
using namespace metarpc;
MT4Sugar sugar("mt4.mrpc.pro", 443);
```

---

## Connection

```cpp
void connect(int64_t login, const std::string& password, const std::string& server,
             const std::string& name = "", int timeoutSeconds = 120);
void quickConnect();   // reads MT4_LOGIN / MT4_PASSWORD / MT4_SERVER from the environment
bool isConnected() const;
bool ping();           // lightweight liveness: fetches the account summary, true on success
void disconnect();     // drop the channel (the terminal keeps running)
```

* `connect(...)` — same arguments as the lower layers; blocks until the terminal is ready.
* `quickConnect()` — one-liner for demos/CI; **throws `std::runtime_error`** if any `MT4_*` env var is missing.
* `ping()` — a cheap "is the link alive?" check.

```cpp
sugar.connect(1235959737, "password", "EGlobal-Demo");
// or, from env vars:
// sugar.quickConnect();

if (sugar.ping()) std::puts("alive");
```

## Balance & margin

```cpp
double getBalance();        // account balance (no floating P/L)
double getEquity();         // balance + floating P/L
double getMargin();         // used margin
double getFreeMargin();     // free margin
double getMarginLevel();    // margin level, %
double getProfit();         // current floating profit (equity - balance)
```

Each reads a fresh account summary. For several figures at once, prefer `getAccountInfo()` (one call) over calling these back-to-back.

```cpp
std::printf("bal %.2f  eq %.2f  free %.2f  float %.2f\n",
            sugar.getBalance(), sugar.getEquity(), sugar.getFreeMargin(), sugar.getProfit());

if (sugar.getMarginLevel() > 0 && sugar.getMarginLevel() < 150)
    std::puts("⚠️ margin level low");
```

## `getAccountInfo()`

```cpp
AccountInfo getAccountInfo();
```

The full account snapshot in one call — `login`, `currency`, `balance`, `equity`, `margin`, `marginFree`, `marginLevel`, `leverage`, `tradeMode`, … *(same `AccountInfo` struct as [MT4Service · Account](../MT4Service/1.%20Account_Information.md).)*

```cpp
AccountInfo a = sugar.getAccountInfo();
std::printf("%lld  %.2f %s  lev 1:%lld  %s\n",
            (long long)a.login, a.equity, a.currency.c_str(), (long long)a.leverage,
            a.tradeAllowed ? "trading on" : "trading off");
```

> **Tip:** `getBalance()` / `getEquity()` / … are convenience wrappers; when you need many fields, one `getAccountInfo()` is cheaper than several getters.

## 🔧 Patterns & worked examples

### Connect from the environment, fail cleanly

```cpp
#include <metarpc/mt4_sugar.hpp>
#include <cstdio>
using namespace metarpc;

int main() {
    MT4Sugar sugar("mt4.mrpc.pro", 443);
    try {
        sugar.quickConnect();                       // reads MT4_LOGIN / MT4_PASSWORD / MT4_SERVER
    } catch (const std::exception& e) {
        std::printf("connect failed: %s\n", e.what());
        return 1;
    }
    std::printf("connected as %lld\n", (long long)sugar.getAccountInfo().login);
}
```

### One-call account dashboard

```cpp
void dashboard(MT4Sugar& sugar) {
    AccountInfo a = sugar.getAccountInfo();          // one round-trip, not six getters
    double floating = a.equity - a.balance;          // MT4 has no profit field
    std::printf("Acc %lld | %s | Bal %.2f | Eq %.2f | Float %+.2f | Free %.2f | Lvl %.0f%%\n",
                (long long)a.login, a.currency.c_str(), a.balance, a.equity,
                floating, a.marginFree, a.marginLevel);
}
```

### Health-gated loop with auto-reconnect check

```cpp
#include <thread>
#include <chrono>
void runWhileHealthy(MT4Sugar& sugar) {
    while (true) {
        if (!sugar.ping()) {                         // cheap liveness probe
            std::puts("link down — backing off");
            std::this_thread::sleep_for(std::chrono::seconds(5));
            continue;
        }
        // ... your per-tick logic using sugar ...
        std::this_thread::sleep_for(std::chrono::seconds(1));
    }
}
```

### Pre-trade affordability guard

```cpp
bool canAfford(MT4Sugar& sugar, double neededMargin) {
    return sugar.getFreeMargin() > neededMargin * 1.5;   // keep 50% headroom
}
```
