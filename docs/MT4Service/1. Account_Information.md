# MT4Service — 1. Account Information

> Account snapshot and performance statistics as **friendly structs** — no protobuf, times in UTC.

Each method delegates to the matching [`MT4Account`](../MT4Account/MT4Account.Master.Overview.md) call and converts the reply. For the full per-field proto detail, follow the links to the MT4Account pages.

```cpp
#include <metarpc/mt4_service.hpp>
using namespace metarpc;

MT4Service svc("mt4.mrpc.pro", 443);
svc.connect(1235959737, "password", "EGlobal-Demo");
```

---

## `accountSummary()`

```cpp
AccountInfo accountSummary();
AccountInfo getAccountInfo();   // legacy alias
```

Full account snapshot in one call. *(Low-level: [AccountSummary](../MT4Account/1.%20Account_Information/AccountSummary.md).)*

**Returns — `AccountInfo`:**

| Field | Type | Description |
|-------|------|-------------|
| `login` | `int64_t` | Account login |
| `currency` | `std::string` | Deposit currency |
| `balance` | `double` | Balance (no floating P/L) |
| `equity` | `double` | Balance + floating P/L |
| `credit` | `double` | Credit |
| `margin` / `marginFree` / `marginLevel` | `double` | Used / free margin, level (%) |
| `leverage` | `int64_t` | e.g. `100` = 1:100 |
| `name` / `company` | `std::string` | Holder / broker name |
| `tradeMode` | `TradeMode` | `Demo` / `Contest` / `Real` |
| `investor` | `bool` | Read-only (investor) login |
| `tradeAllowed` / `tradeExpert` | `bool` | Manual / EA trading permitted |
| `serverTime` / `serverTimeUtc` | `int64_t` | Broker / UTC time (unix sec) |
| `utcShiftMinutes` | `int64_t` | Broker clock minus UTC (minutes) |
| `server` | `std::string` | Broker server name |

```cpp
AccountInfo a = svc.accountSummary();
std::printf("%lld  bal %.2f  eq %.2f  free %.2f %s\n",
            (long long)a.login, a.balance, a.equity, a.marginFree, a.currency.c_str());
double floating = a.equity - a.balance;   // MT4 has no dedicated profit field
```

> **🆚** Unlike MT5, `AccountInfo` already carries the margin fields — no separate margin call.

## `tradeStats()`

```cpp
TradeStats tradeStats();
```

Headline performance statistics over the account history. *(Low-level: [TradeStats](../MT4Account/1.%20Account_Information/TradeStats.md) — the facade reads the whole history; use the low-level `from` for a window.)*

**Returns — `TradeStats` (friendly subset of ~29 fields):**

| Field | Type | Description |
|-------|------|-------------|
| `trades` | `int64_t` | Number of trades |
| `profitFactor` | `double` | Gross profit / gross loss |
| `sharpeRatio` / `standardDeviation` / `ghpr` | `double` | Risk-adjusted metrics |
| `pips` / `lots` / `commissions` | `double` | Totals |
| `growthPercent` | `double` | Account growth (%) |
| `maxBalanceDrawdownRaw` / `…Relative` | `double` | Balance drawdown (money / %) |
| `maxEquityDrawdownRaw` / `…Relative` | `double` | Equity drawdown (money / %) |
| `deposits` / `withdrawals` | `double` | Cash flows |
| `openTrades`, `openProfit` | `int`, `double` | Currently open |
| `dayProfit` / `weekProfit` / `monthProfit` / `totalProfit` | `double` | Period profits |
| `averageTradeLength` | `std::string` | Human-readable duration |

```cpp
TradeStats s = svc.tradeStats();
std::printf("PF %.2f over %lld trades, max equity DD %.1f%%\n",
            s.profitFactor, (long long)s.trades, s.maxEquityDrawdownRelative);
```

## `equityHistory()`

```cpp
std::vector<EquityPoint> equityHistory();
```

The balance/equity curve points. *(Low-level: [EquityHistory](../MT4Account/1.%20Account_Information/EquityHistory.md).)*

**Returns — `std::vector<EquityPoint>`, each:**

| Field | Type | Description |
|-------|------|-------------|
| `time` | `int64_t` | Point time, unix sec (UTC) |
| `balance` / `equity` | `double` | Balance / equity at the point |
| `realizedPL` / `unrealizedPL` | `double` | Realized / floating P/L |
| `cashFlow` | `double` | Deposit/withdrawal at the point |
| `balanceDrawdownRaw` / `equityDrawdownRaw` | `double` | Drawdowns (money) |

```cpp
auto curve = svc.equityHistory();
double peak = 0, maxDD = 0;
for (const auto& p : curve) { peak = std::max(peak, p.equity); maxDD = std::max(maxDD, peak - p.equity); }
std::printf("%zu points, max DD %.2f\n", curve.size(), maxDD);
```

## `tradeUnrealizedPL()`

```cpp
std::vector<UnrealizedExtremum> tradeUnrealizedPL();
```

The max/min floating P/L (MFE/MAE) reached per currently open order. *(Low-level: [TradeUnrealizedPL](../MT4Account/1.%20Account_Information/TradeUnrealizedPL.md).)*

**Returns — `std::vector<UnrealizedExtremum>`, each:**

| Field | Type | Description |
|-------|------|-------------|
| `ticket` | `int64_t` | Order ticket |
| `symbol` | `std::string` | Instrument |
| `maxPL` / `maxTime` | `double` / `int64_t` | Best floating profit (MFE) + when |
| `minPL` / `minTime` | `double` / `int64_t` | Worst floating P/L (MAE) + when |

```cpp
for (const auto& e : svc.tradeUnrealizedPL())
    std::printf("#%lld %-8s MFE %.2f MAE %.2f\n",
                (long long)e.ticket, e.symbol.c_str(), e.maxPL, e.minPL);
```

> The facade does not wrap `tradeStatsEquityHistory` (stats+curve+trades in one call) — use `account().tradeStatsEquityHistory(...)` on the low-level layer if you need the combined payload.
