# MT4Service — 4. Trading Operations

> Place, modify, close and net orders with **plain arguments**. The facade builds the request and casts enums; a `OrderRequest` struct carries everything `orderSend` needs.

> **🛑 Still no retcode.** A rejected trade **throws `metarpc::ApiError`** (MQL4 code in `mqlErrorCode`) — `orderSend` / `orderClose` / `orderCloseBy` surface the throw. `orderModify` returns a `bool`. Wrap trades in `try/catch (const ApiError&)`. See the low-level [Trading Operations overview](../MT4Account/4.%20Trading_Operations/Trading_Operations.Overview.md) for the MQL4 code table.

```cpp
MT4Service svc("mt4.mrpc.pro", 443);
svc.connect(1235959737, "password", "EGlobal-Demo");
```

## `orderSend(OrderRequest)`

```cpp
OrderResult orderSend(const OrderRequest& request);
```

Place a market or pending order. *(Low-level: [OrderSend](../MT4Account/4.%20Trading_Operations/OrderSend.md).)*

**Input — `OrderRequest`:**

| Field | Type | Description |
|-------|------|-------------|
| `symbol` | `std::string` | Instrument |
| `type` | `OrderType` | `Buy`/`Sell` (market) or `*Limit`/`*Stop` (pending) |
| `volume` | `double` | Lots |
| `price` | `double` | `0` = market for Buy/Sell; **required for pendings** |
| `stopLoss` / `takeProfit` | `double` | SL / TP **prices** (0 = none) |
| `slippage` | `int` | Max deviation (points), default `10` |
| `magic` | `int32_t` | Strategy tag |
| `comment` | `std::string` | Order comment |
| `expiration` | `int64_t` | Pending expiry, unix sec (UTC); 0 = GTC |

**Returns — `OrderResult`:** `ticket`, `volume` (filled), `price` (fill), `openTime`; `ok()` = `ticket != 0`.

```cpp
OrderRequest req;
req.symbol = "EURUSD";
req.type   = OrderType::Buy;
req.volume = 0.10;
req.stopLoss = 1.09500;  req.takeProfit = 1.10500;   // prices
try {
    OrderResult r = svc.orderSend(req);
    std::printf("opened #%d @ %.5f\n", r.ticket, r.price);
} catch (const ApiError& e) {
    std::printf("rejected: %s (MQL4 %d)\n", e.what(), e.mqlErrorCode);
}
```

## `orderModify(ticket, sl, tp, price=0, expiration=0)`

```cpp
bool orderModify(int32_t ticket, double stopLoss, double takeProfit,
                 double price = 0, int64_t expiration = 0);
```

Change SL/TP (and `price`/`expiration` for pendings). Returns whether the terminal applied the change (and returns `false` instead of throwing on an ordinary rejection). *(Low-level: [OrderModify](../MT4Account/4.%20Trading_Operations/OrderModify.md).)*

```cpp
if (svc.orderModify(ticket, /*sl*/ 1.09000, /*tp*/ 1.11000))
    std::puts("SL/TP updated");
```

---

## `orderClose(ticket, lots=0, price=0, slippage=10)`

```cpp
void orderClose(int32_t ticket, double lots = 0, double price = 0, int slippage = 10);
```

Close a market order (`lots = 0` → the whole order; a smaller value → partial) **or delete a pending** order. *(Low-level: [OrderCloseDelete](../MT4Account/4.%20Trading_Operations/OrderCloseDelete.md).)*

```cpp
try { svc.orderClose(ticket); }                 // full close / delete
catch (const ApiError& e) { std::printf("close failed: %s\n", e.what()); }

svc.orderClose(ticket, /*lots*/ 0.05);          // partial close
```

## `orderCloseBy(ticket, oppositeTicket)`

```cpp
CloseByResult orderCloseBy(int32_t ticket, int32_t oppositeTicket);
```

Close an order against an **opposite** order on the **same symbol** (netting a hedge). *(Low-level: [OrderCloseBy](../MT4Account/4.%20Trading_Operations/OrderCloseBy.md).)*

**Returns — `CloseByResult`:** `closePrice`, `profit`, `closeTime` (unix sec, UTC).

```cpp
try {
    CloseByResult r = svc.orderCloseBy(buyTicket, sellTicket);
    std::printf("netted @ %.5f  profit %.2f\n", r.closePrice, r.profit);
} catch (const ApiError& e) { std::printf("close-by failed: %s\n", e.what()); }
```
