# MT4Service — 5. Streaming Methods

> Real-time streams delivering **friendly structs** (times in UTC) to your callback on a background thread. Each returns a `std::unique_ptr<ServiceStream>` — keep it alive to keep receiving; `stop()` / destroy to cancel.

```cpp
class ServiceStream {
    void stop();                    // cancel + join the reader thread
    bool running() const;           // false once ended/cancelled
    uint64_t count() const;         // payloads delivered so far
    std::string lastError() const;  // reason it ended, or "" if clean
};
```

> **Thread safety:** the callback runs on another thread — synchronize shared state and keep it short. *(Low-level: [Streaming Methods overview](../MT4Account/5.%20Streaming_Methods/Streaming_Methods.Overview.md).)*

```cpp
MT4Service svc("mt4.mrpc.pro", 443);
svc.connect(1235959737, "password", "EGlobal-Demo");
```

## `subscribeTicks(symbols, cb)`

```cpp
std::unique_ptr<ServiceStream> subscribeTicks(
    const std::vector<std::string>& symbols, std::function<void(const Tick&)> callback);
```

Live ticks for the given symbols. *(Low-level: [OnSymbolTick](../MT4Account/5.%20Streaming_Methods/OnSymbolTick.md).)*

**Delivers — `Tick`:** `symbol`, `time` (unix sec, UTC), `timeMsc`, `bid`, `ask`, **`last`**, **`volume`**. *(Unlike the unary `quote`, ticks carry `last` and `volume`.)*

```cpp
auto s = svc.subscribeTicks({"EURUSD"}, [](const Tick& t) {
    std::printf("%s %.5f/%.5f last %.5f vol %llu\n",
                t.symbol.c_str(), t.bid, t.ask, t.last, (unsigned long long)t.volume);
});
std::this_thread::sleep_for(std::chrono::seconds(5));
s->stop();
```

## `streamTradeUpdates(cb)`

```cpp
std::unique_ptr<ServiceStream> streamTradeUpdates(std::function<void(const TradeEvent&)> callback);
```

Order lifecycle events — opened / changed / closed / new-history. *(Low-level: [OnTrade](../MT4Account/5.%20Streaming_Methods/OnTrade.md).)*

**Delivers — `TradeEvent`:**

| Field | Type | Description |
|-------|------|-------------|
| `type` | `int` | Event group (`OrderProfit` / `OrderUpdate`) |
| `account` | `EventAccountInfo` | Account snapshot (`balance`/`equity`/`margin`/`profit`/…) |
| `newOrders` | `std::vector<TradeOrderInfo>` | Just appeared |
| `updatedOrders` | `std::vector<OrderChange>` | `{previous, current}` pairs |
| `removedOrders` | `std::vector<TradeOrderInfo>` | Removed / closed |
| `newHistoryOrders` | `std::vector<TradeOrderInfo>` | Landed in history |

```cpp
auto s = svc.streamTradeUpdates([](const TradeEvent& e) {
    for (const auto& o : e.newOrders)     std::printf("+ #%d %s\n", o.ticket, o.symbol.c_str());
    for (const auto& o : e.removedOrders) std::printf("- #%d profit %.2f\n", o.ticket, o.profit);
});
```

## `streamOrderProfits(cb, periodMs=1000)`

```cpp
std::unique_ptr<ServiceStream> streamOrderProfits(
    std::function<void(const OrderProfitEvent&)> callback, int periodMs = 1000);
```

Periodic floating-P/L snapshots of the open orders (server timer). *(Low-level: [OnOpenedOrdersProfit](../MT4Account/5.%20Streaming_Methods/OnOpenedOrdersProfit.md).)*

**Delivers — `OrderProfitEvent`:** `type`, `account` (`EventAccountInfo`), `orders` (`std::vector<OrderProfitInfo>`: `ticket`, `symbol`, `type`, `lots`, `openPrice`, `profit`, `swap`, `commission`, …).

```cpp
auto s = svc.streamOrderProfits([](const OrderProfitEvent& e) {
    double total = 0; for (const auto& o : e.orders) total += o.profit;
    std::printf("\rFloating P/L %.2f (%zu orders)", total, e.orders.size());
    std::fflush(stdout);
}, /*periodMs*/ 500);
```

## `streamOpenedTickets(cb, intervalMs=1000)`

```cpp
std::unique_ptr<ServiceStream> streamOpenedTickets(
    std::function<void(const TicketsSnapshot&)> callback, int intervalMs = 1000);
```

Periodic ticket snapshots — market vs pending, split. *(Low-level: [OnOpenedOrdersTickets](../MT4Account/5.%20Streaming_Methods/OnOpenedOrdersTickets.md).)*

**Delivers — `TicketsSnapshot`:** `positionTickets` (market), `pendingOrderTickets`, `serverTime` (unix sec, UTC), `terminalGuid`.

```cpp
auto s = svc.streamOpenedTickets([](const TicketsSnapshot& t) {
    std::printf("\rmarket %zu  pending %zu",
                t.positionTickets.size(), t.pendingOrderTickets.size());
    std::fflush(stdout);
});
```

## `streamConnectState(cb)`

```cpp
std::unique_ptr<ServiceStream> streamConnectState(std::function<void(const ConnectState&)> callback);
```

Terminal connection-state changes. *(Low-level: [OnConnectState](../MT4Account/5.%20Streaming_Methods/OnConnectState.md).)*

**Delivers — `ConnectState`:** `id`, `state`, `isConnected`, `isAlive`, `apiIsAlive`, `server`, `account`, `errorMessage`, `timestamp` (unix sec, UTC).

```cpp
std::atomic<bool> healthy{true};
auto s = svc.streamConnectState([&](const ConnectState& st) {
    healthy = st.isConnected && st.isAlive && st.apiIsAlive;
    if (!healthy) std::printf("⚠️ link down: %s\n", st.errorMessage.c_str());
});
```
