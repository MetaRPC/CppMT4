# MT4Service — 2. Orders & History

> Live orders and closed history as **friendly structs**. MT4 has **no "positions"** — market and pending orders share one `Order` list; tell them apart with `isPending()` / `isBuy()`.

```cpp
MT4Service svc("mt4.mrpc.pro", 443);
svc.connect(1235959737, "password", "EGlobal-Demo");
```

---

## `openedOrders()` / `openedOrders(magic)`

```cpp
std::vector<Order> openedOrders();
std::vector<Order> openedOrders(int32_t magic);   // filtered by magic number
```

All live orders (market **and** pending), optionally filtered by magic number. *(Low-level: [OpenedOrders](../MT4Account/2.%20Orders_History/OpenedOrders.md).)*

**Returns — `std::vector<Order>`, each:**

| Field | Type | Description |
|-------|------|-------------|
| `ticket` | `int32_t` | Order ticket |
| `symbol` | `std::string` | Instrument |
| `type` | `OrderType` | `Buy`/`Sell` (market) or `*Limit`/`*Stop` (pending) |
| `lots` | `double` | Volume |
| `openPrice` | `double` | Entry / trigger price |
| `stopLoss` / `takeProfit` | `double` | SL / TP (0 = none) |
| `profit` / `swap` / `commission` | `double` | Floating P/L / swap / commission |
| `magic` | `int32_t` | Strategy tag |
| `comment` | `std::string` | Order comment |
| `openTime` / `expirationTime` | `int64_t` | Open / pending expiry, unix sec (UTC); expiry 0 = GTC |

**Helpers:** `o.isPending()` (pending vs market), `o.isBuy()` (buy-side).

```cpp
for (const auto& o : svc.openedOrders())
    std::printf("#%d %-8s %s %.2f  P/L %.2f\n",
                o.ticket, o.symbol.c_str(), o.isPending() ? "PENDING" : "MARKET", o.lots, o.profit);

// only this strategy's orders
auto mine = svc.openedOrders(/*magic*/ 777);
```

## `openedOrdersTickets()`

```cpp
std::vector<int32_t> openedOrdersTickets();
```

Just the ticket numbers of all live orders — the lightweight poll. *(Low-level: [OpenedOrdersTickets](../MT4Account/2.%20Orders_History/OpenedOrdersTickets.md).)*

```cpp
auto tickets = svc.openedOrdersTickets();
std::printf("%zu open orders\n", tickets.size());
```

## `ordersHistory(fromUnix, toUnix)`

```cpp
std::vector<HistoryOrder> ordersHistory(int64_t fromUnix, int64_t toUnix);
```

Closed orders in a **UTC** window (unix seconds). *(Low-level: [OrdersHistory](../MT4Account/2.%20Orders_History/OrdersHistory.md).)*

**Returns — `std::vector<HistoryOrder>`, each:** the `Order` fields **plus** `closePrice` and `closeTime` (unix sec, UTC).

```cpp
#include <ctime>
int64_t now = (int64_t)std::time(nullptr);
auto hist = svc.ordersHistory(now - 7*24*3600, now);     // last 7 days

double realized = 0;
for (const auto& h : hist) {
    if (h.type == OrderType::Balance || h.type == OrderType::Credit) continue;  // skip non-trades
    realized += h.profit + h.swap + h.commission;
}
std::printf("%zu closed, realized %.2f\n", hist.size(), realized);
```

> **Filter out** `OrderType::Balance` / `OrderType::Credit` — they're deposits/credits, not trades.
