# MT4Service — 3. Symbols & Quotes

> Prices, the symbol inventory, parameters, tick value, bars — and the time helpers — as **friendly structs**, times in UTC.

```cpp
MT4Service svc("mt4.mrpc.pro", 443);
svc.connect(1235959737, "password", "EGlobal-Demo");
```

---

## `quote(symbol)` / `quoteMany(symbols)`

```cpp
Quote quote(const std::string& symbol);
std::vector<Quote> quoteMany(const std::vector<std::string>& symbols);
```

Latest price(s). *(Low-level: [Quote](../MT4Account/3.%20Symbols_Quotes/Quote.md) · [QuoteMany](../MT4Account/3.%20Symbols_Quotes/QuoteMany.md).)*

**Returns — `Quote`:**

| Field | Type | Description |
|-------|------|-------------|
| `symbol` | `std::string` | Instrument |
| `time` | `int64_t` | Quote time, unix sec (UTC) |
| `bid` / `ask` | `double` | Current prices |
| `high` / `low` | `double` | Session high / low |

**Helper:** `q.twoSided()` (bid & ask valid). *(No `last`/`volume` on quotes — those come from ticks; see [5. Streaming](./5.%20Streaming_Methods.md).)*

```cpp
Quote q = svc.quote("EURUSD");
std::printf("%s %.5f / %.5f\n", q.symbol.c_str(), q.bid, q.ask);

for (const auto& x : svc.quoteMany({"EURUSD","GBPUSD","XAUUSD"}))
    std::printf("  %-8s %.5f\n", x.symbol.c_str(), x.bid);
```

## `symbolSelect(symbol, select=true)`

```cpp
bool symbolSelect(const std::string& symbol, bool select = true);
```

Add/remove a symbol from Market Watch — **required before a symbol quotes or trades**. Returns `success`. *(Low-level: [SymbolSelect](../MT4Account/3.%20Symbols_Quotes/SymbolSelect.md).)*

```cpp
if (svc.symbolSelect("XAUUSD")) { /* now safe to quote/trade */ }
```

## `symbolParams(symbol)` / `symbolParamsMany(nameFilter="")`

```cpp
SymbolInfo symbolParams(const std::string& symbol);
std::vector<SymbolInfo> symbolParamsMany(const std::string& nameFilter = "");
```

Full contract spec (the useful subset of 67 fields). `symbolParamsMany("")` returns **all** symbols. *(Low-level: [SymbolParamsMany](../MT4Account/3.%20Symbols_Quotes/SymbolParamsMany.md).)*

**Returns — `SymbolInfo` (key fields):**

| Field | Type | Description |
|-------|------|-------------|
| `name` / `description` / `path` | `std::string` | Identity |
| `digits` / `point` | `int` / `double` | Price precision |
| `contractSize` | `double` | e.g. `100000` for FX |
| `tickValue` / `tickSize` | `double` | P&L inputs |
| `volumeMin` / `volumeMax` / `volumeStep` | `double` | Volume grid |
| `stopsLevel` / `freezeLevel` | `int` | Min SL/TP & freeze distance (points) |
| `tradeMode` | `int` | 0 DISABLED…4 FULL |
| `marginInitial` | `double` | Margin per lot |
| `currencyBase` / `currencyProfit` / `currencyMargin` | `std::string` | Currencies |
| `swapLong` / `swapShort` | `double` | Swaps |
| `selected` / `visible` | `bool` | In Market Watch / visible |

```cpp
SymbolInfo s = svc.symbolParams("EURUSD");
double pip = (s.digits == 3 || s.digits == 5) ? s.point * 10 : s.point;
std::printf("%s digits=%d pip=%.5f contract=%.0f\n", s.name.c_str(), s.digits, pip, s.contractSize);
```

## `tickValueWithSize(symbols)`

```cpp
std::vector<TickValueSize> tickValueWithSize(const std::vector<std::string>& symbols);
```

Tick value / tick size / contract size per symbol — the inputs for client-side P&L and sizing (MT4 has no server calculator). *(Low-level: [TickValueWithSize](../MT4Account/3.%20Symbols_Quotes/TickValueWithSize.md).)*

**Returns — `std::vector<TickValueSize>`, each:** `symbol`, `tickValue`, `tickSize`, `contractSize`.

```cpp
for (const auto& t : svc.tickValueWithSize({"EURUSD","XAUUSD"}))
    std::printf("%-8s tickVal %.5f size %.5f\n", t.symbol.c_str(), t.tickValue, t.tickSize);
```

## `bars(symbol, tf, fromUnix, toUnix, maxBars=0)` / `lastBars(symbol, tf, count)`

```cpp
std::vector<Bar> bars(const std::string& symbol, Timeframe tf,
                      int64_t fromUnix, int64_t toUnix, int maxBars = 0);
std::vector<Bar> lastBars(const std::string& symbol, Timeframe tf, int count);
```

OHLC bars over a **UTC** window, or the newest `count` bars. `Timeframe` values are **minutes** (`M1=1 … H1=60 … D1=1440`). `lastBars` supplies the required `from_time` for you. *(Low-level: [Bars](../MT4Account/3.%20Symbols_Quotes/Bars.md).)*

**Returns — `std::vector<Bar>`, each:** `time` (unix sec, UTC), `open`, `high`, `low`, `close`, `tickVolume`, `realVolume`, `spread`.

```cpp
auto bars = svc.lastBars("EURUSD", Timeframe::H1, 100);   // newest 100 H1 bars
if (!bars.empty())
    std::printf("last close %.5f\n", bars.back().close);
```

> **🆚** `bars` uses the minute-count timeframe scheme; the low-level `quoteHistory` uses a *different* index enum. The facade standardizes on `Timeframe` (minutes).

## Time helpers

```cpp
int64_t serverOffsetSeconds();        // broker clock minus UTC (seconds), cached
int64_t toUtc(int64_t serverTime);    // raw broker time -> UTC
int64_t toServerTime(int64_t utc);    // UTC -> raw broker time
ServerTimezoneInfo serverTimezone();  // name, offset, source, validated-at
```

*(Low-level: [ServerTimezone](../MT4Account/3.%20Symbols_Quotes/ServerTimezone.md).)*

**Returns — `ServerTimezoneInfo`:** `server`, `utcOffsetSeconds`, `source`, `validatedUtc`.

```cpp
ServerTimezoneInfo tz = svc.serverTimezone();
std::printf("%s  UTC%+d h\n", tz.server.c_str(), tz.utcOffsetSeconds / 3600);
```
