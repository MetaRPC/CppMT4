# CppMT4 SDK

> High-performance modern C++ SDK for MetaTrader 4 algorithmic trading automation.

[![Docs](https://img.shields.io/badge/docs-metarpc.github.io%2FCppMT4-blue.svg)](https://metarpc.github.io/CppMT4/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Features

- **Direct Socket Connection**: Fast, low-latency C++ TCP connection directly to MetaTrader 4 servers.
- **Zero GUI Dependency**: Pure C++ client without desktop MetaTrader or Wine.
- **Modern C++ API**: Modern C++17/20 interfaces with standard types (`std::function`, `std::vector`, `std::string`).
- **Complete Trading Suite**: Real-time quotes, market & pending orders, position modification and closing.
